# Веб-интерфейс (локальная обкатка)

Чертёж → распознавание → состав → смета → Excel, в браузере.
Тот же расчётный путь, что у бота: `analyze_page` → `calculate_full_cost`,
документы берут снимок `quote` (`quote_from_result`). Второго счётчика нет.

## Запуск

```powershell
.\.venv\Scripts\python.exe scripts\run_web.py
```

Откроется `http://127.0.0.1:8000/`. Остановка — `Ctrl+C`.

Без автооткрытия браузера:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.web.server:app --host 127.0.0.1 --port 8000
```

## Что умеет (MVP)

| Действие | Результат |
|---|---|
| Перетащить JPG/PNG/WEBP/BMP | распознавание состава |
| Таблица состава | тип модуля, Ш×Г×В, корпусов, дверей, ящиков |
| Итоги | себестоимость, наличные, безнал |
| Предупреждения | флаги качества распознавания, позиции без цены, блокировка КП |
| «Скачать Excel» | файл из снимка расчёта (шаблон `templates/Таблица для расчетов пустая.xlsx`) |
| «Скачать КП (Word)» | DOCX с вариантами: Базовая / Стандарт / Комфорт |

## Коммерческое предложение

Собирается в **DOCX** — правится в Word (текст, цены, состав — обычные абзацы
и таблицы, не картинка).

Что можно задать в вебе перед скачиванием:

| Поле | Влияние |
|---|---|
| Заказчик | строка «Заказчик: …» в шапке |
| Скидка, % | уменьшает все варианты (0–30) |
| Действует, дней | дата «предложение действительно до» |
| Галочки вариантов | какие варианты попадут в КП |
| LED / GOLA / наполнение | дополнительные опции, пересчитываются движком |
| Эскиз чертежа | вставить распознанный лист в конец КП |

Варианты считаются тем же движком (`calculate_full_cost`), меняются материалы
и фурнитура: базовая — ТОМЛЕСДРЕВ + ПВХ + СТАРТ, стандарт — EGGER + акрил
матовый + Боярд, комфорт — LAMARTY + акрил глянец + LEGRABOX/Blum.

Структура документа: шапка с реквизитами (из `.env`: `COMPANY_LEGAL_NAME`,
`COMPANY_INN` и т.д.), заголовок и срок действия, сводная таблица вариантов,
затем по каждому варианту — описание, материалы, состав (модуль, размеры,
корпуса, двери, ящики) и цены «наличные / безнал», в конце — опции, условия
и контакты.

## Ограничения MVP

- **Только локально.** Сервер слушает `127.0.0.1`, авторизации нет — для одного
  пользователя на своём компьютере. В локальную сеть или интернет так нельзя:
  там сметы клиентов.
- **Материалы по умолчанию.** Берутся самые дешёвые активные позиции из прайса
  (ЛДСП, кромка, фасады, петли, ящики). Выбора материалов в вебе пока нет —
  это следующий шаг.
- **Позиции без цены блокируют КП.** ХДФ, конфирмат, опора, цоколь, штанга —
  их нет в прайсе, поэтому `can_issue_kp=false`; Excel при этом формируется
  с нулевой ценой по этим строкам.
- **Снимки расчётов в памяти.** После перезапуска сервера ссылка на Excel
  перестаёт работать — распознайте заново.
- **Распознавание требует интернет** (DeepSeek). Офлайн веб не заработает.

## PDF

Пока принимаются только изображения. Для PDF нужно рендерить страницы
через `pdf_renderer` — это следующий шаг вместе с выбором страницы.
