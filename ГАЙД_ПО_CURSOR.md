## ШАГ 0. Подготовка (30 минут)

### Что установить

1. **Cursor** — скачай с https://cursor.com и установи. Это как VS Code, но с AI внутри. Бесплатный тариф даёт ~50 запросов к AI в день — этого хватит.

2. **Python 3.12** — скачай с https://python.org. При установке на Windows обязательно поставь галку «Add Python to PATH».

3. **Git** — скачай с https://git-scm.com. Нужен для контроля версий (откат если что-то сломается).

4. **Telegram-бот** — зайди в Telegram, найди @BotFather, отправь `/newbot`, придумай имя. Он даст тебе токен вида `123456:ABC-DEF...` — сохрани его.

5. **Gemini API ключ** — зайди на https://aistudio.google.com/apikey, нажми «Create API Key». Сохрани ключ.

### Создать папку проекта

Открой терминал (на Windows: PowerShell, на Mac: Terminal) и набери:

```
mkdir furniture-calc
cd furniture-calc
git init
```

Теперь открой эту папку в Cursor: запусти Cursor → File → Open Folder → выбери `furniture-calc`.

### Положить файлы-инструкции в проект

В Cursor в левой панели (Explorer) нажми правой кнопкой → New File. Создай два файла:

1. **`.cursorrules`** — скопируй туда:
```
Проект: Telegram-бот для расчёта стоимости корпусной мебели.
Стек: Python 3.12, FastAPI, aiogram 3, SQLite, openpyxl, ReportLab.

Правила:
- Пиши на Python 3.12 с type hints
- Используй async/await везде
- Модели данных — SQLAlchemy 2.0
- FSM для Telegram — через aiogram StatesGroup
- Все цены в рублях, Float
- Комментарии на русском
- Не используй print() — используй logging
```

2. **`CURSOR_INSTRUCTIONS_v2.md`** — скопируй туда содержимое файла с техническими инструкциями (который мы подготовили ранее). Это «мозг» проекта — Cursor будет читать его при каждом запросе.

3. **Прайс-файл** — скопируй `Расчет_кухня_1.xlsx` в папку проекта.

## ШАГ 1. Знакомство с Cursor (15 минут)

### Три главных инструмента

В Cursor есть три способа общаться с AI. Запомни их:

**Composer (Cmd+I на Mac / Ctrl+I на Windows)** — главный инструмент. Здесь ты описываешь задачу, и Cursor создаёт/изменяет файлы. Используй для создания нового кода.

**Chat (Cmd+L / Ctrl+L)** — для вопросов и отладки. Сюда копируй ошибки из терминала. Chat не меняет файлы — только отвечает.

**Inline Edit (Cmd+K / Ctrl+K)** — выдели кусок кода → нажми Cmd+K → опиши что изменить. Для точечных правок.

### Золотое правило

**Один промпт = одна задача.** Не пытайся создать всё за один запрос. Делай маленькие шаги, после каждого проверяй что всё работает.

### Как ссылаться на файлы

В Composer можно писать `@имя_файла` чтобы Cursor видел контекст. Например:
- `@CURSOR_INSTRUCTIONS_v2.md` — подключить спецификацию
- `@app/services/cost_calc.py` — показать конкретный файл

## ШАГ 2. Создаём каркас проекта

### 2.1. Открой Composer (Cmd+I) и напиши:

```
@CURSOR_INSTRUCTIONS_v2.md

Создай структуру проекта по дереву из ЧАСТИ 2 этого файла.

Создай все папки и пустые __init__.py файлы.
Создай requirements.txt (скопируй из ЧАСТИ 7).
Создай .env.example (скопируй из ЧАСТИ 7).
Создай Dockerfile и docker-compose.yml (скопируй из ЧАСТИ 7).
Создай app/config.py с Pydantic Settings — загрузка переменных из .env.

Пока не пиши логику — только скелет проекта.
```

Cursor покажет план создания файлов. **Нажми «Accept All»** (или зелёную кнопку) чтобы применить.

### 2.2. Настрой .env

В левой панели найди файл `.env.example`. Скопируй его:
- Правой кнопкой по файлу → Copy
- Правой кнопкой в пустом месте → Paste
- Переименуй копию в `.env`
- Открой `.env` и впиши свои данные:
  - `TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather`
  - `GEMINI_API_KEY=твой_ключ_от_Google`

### 2.3. Установи зависимости

Открой терминал в Cursor (Ctrl+` — кнопка с обратной кавычкой, слева от 1):

```
pip install -r requirements.txt
```

Если появятся ошибки — скопируй их и вставь в Chat (Cmd+L):
```
Вот ошибка при установке зависимостей. Как исправить?
[вставь ошибку]
```

### 2.4. Проверка

В терминале набери:
```
python -c "import aiogram; print('OK')"
```
Если видишь `OK` — всё установлено. Если ошибка — снова в Chat с текстом ошибки.

## ШАГ 3. Модели данных и запуск бота

### 3.1. Composer (Cmd+I):

```
@CURSOR_INSTRUCTIONS_v2.md

Создай модели SQLAlchemy в app/models/ по спецификации из ЧАСТИ 3 этого файла.

Нужны модели:
- PriceItem с полем requires_manual_price (из ЧАСТИ 9.1)
- PriceHistory
- GlassType
- Project
- Calculation (с полями для скидок/наценок/бонусов из ЧАСТИ 3)
- CommercialOffer
- CalcSettings

Также создай:
- app/models/base.py
- app/db/session.py — async sessionmaker для SQLite
- Начальную Alembic миграцию

И создай app/main.py который:
1. Создаёт таблицы в SQLite при запуске
2. Инициализирует aiogram Bot с токеном из .env
3. Подключает router из app/bot/handlers/start.py
4. Запускает бот через polling
```

Нажми Accept All.

### 3.2. Composer (Cmd+I):

```
Создай app/bot/handlers/start.py:

Обработчик /start — бот отвечает:
"Привет! Я помогу рассчитать стоимость мебели.
Выберите действие:"

Reply-клавиатура:
[📁 Новый проект] [📋 Мои проекты]
[💰 Прайс] [⚙️ Настройки]

Используй aiogram 3 Router.
```

### 3.3. Первый запуск!

В терминале:
```
python -m app.main
```

Открой Telegram, найди своего бота, нажми /start. Если бот ответил с клавиатурой — **поздравляю, скелет работает!**

Если ошибка:
1. Скопируй ошибку из терминала
2. Открой Chat (Cmd+L)
3. Вставь: `Бот не запускается. Вот ошибка: [ошибка]. Исправь.`
4. Cursor предложит решение — примени его

### 3.4. Сохрани прогресс

В терминале:
```
git add .
git commit -m "Каркас проекта + бот отвечает на /start"
```

Это «точка сохранения». Если потом что-то сломается, можно откатить:
```
git checkout .
```

**Делай `git commit` после каждого успешного шага!**

```
@CURSOR_INSTRUCTIONS_v2.md

Реализуй ручной ввод модулей мебели.

Кнопка [✏️ Вручную]:
1. Тип модуля (inline): Нижняя база | Верхняя база | Пенал | Колонна | Тумба
2. Ширина: кнопки 300|400|450|500|600|800|900 + [Другая]
3. Глубина: 320 (верхние) | 560 (нижние) по умолчанию
4. Высота: 720|820|2100 по умолчанию
5. Наполнение: Двери | Ящики | Полки | Подъёмник | Бутылочница
6. Кол-во дверей/ящиков
7. Стекло в фасаде? Да/Нет

После ввода: [➕ Ещё модуль] [✅ Готово]
```

### 5.3. Composer:

```
@CURSOR_INSTRUCTIONS_v2.md

Реализуй выбор материалов из прайса через inline-кнопки.

Последовательно:
1. ЛДСП — загрузить из БД category="ЛДСП", показать кнопками с ценами
2. Фасады — сначала категория (МДФ|ЭФТРИ|ЛАКОКРАСКА|АЛЮМ), потом позиция
3. Кромка — автоматически подобрать по производителю ЛДСП
4. Петли — BOYARD|BLUM|HETTICH, потом модель
5. Ящики (если есть) — BOYARD СТАРТ|HETTICH|BLUM TANDEMBOX|LEGRABOX

Если позиция с requires_manual_price=1 — спросить цену у оператора.
Формула фасадов на заказ: цена_за_м² × площадь (ЧАСТЬ 9.4).
```

### 5.4. Тест

Запусти бота. Пройди весь путь: Новый проект → ФИО → Телефон → Адрес → Вручную → добавь пару модулей → выбери материалы.

## СОВЕТЫ И ЧАСТЫЕ ПРОБЛЕМЫ

### Cursor создаёт слишком много файлов за раз

Если после промпта Cursor показывает изменения в 10+ файлах — это плохой знак. Нажми «Reject All» и переформулируй задачу уже. Один промпт = 1-3 файла максимум.

### Cursor «забывает» контекст

Если Cursor генерирует код, который не соответствует спецификации:
```
@CURSOR_INSTRUCTIONS_v2.md

Прочитай ЧАСТЬ 10 "Сводка бизнес-правил" и исправь файл 
app/services/cost_calc.py — формулы не соответствуют спецификации.
```

### Cursor ломает работающий код

Это частая проблема. Поэтому:
1. `git commit` после каждого работающего шага
2. Если сломал — `git diff` покажет что изменилось
3. `git checkout путь/к/файлу` — откатить один файл

### Бот не запускается

Самые частые причины:
- Не заполнен `.env` (нет токена)
- Ошибка импорта (файл не найден) — проверь структуру папок
- Циклический импорт — скажи Cursor: `Циклический импорт в app/. Исправь порядок импортов.`

### Расчёт даёт неправильные цифры

Открой Chat, скажи:
```
Расчёт даёт себестоимость 50000, а должно быть 72000.
Входные данные: ЛДСП EXTRAVERT текстуры 4 листа, петли Boyard 14 шт, ...
Проверь формулы в app/services/cost_calc.py по спецификации из @CURSOR_INSTRUCTIONS_v2.md ЧАСТЬ 10.
```

### Как делать «git commit» проще

В Cursor есть встроенный Git. Слева внизу — иконка ветки. Нажми на неё → Source Control. Там можно коммитить одной кнопкой.
