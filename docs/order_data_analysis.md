# Анализ выгрузки заказов «ФИНАНСЫ ПРОМЕБЕЛЬ»

**Дата анализа:** 17.11.2026.  
**Персональные данные:** в отчёт не включаются; используются только номера заказов и агрегаты.  
**Связь:** `docs/financial_policy_v1.0.md`, `docs/financial_data_request.md`.

## 2. Наценка по плановой себестоимости

Выборка: 20 заказов, где есть цена и «Итого себестоимость».

| Показатель | Значение |
|---|---:|
| Минимум | 21,3% |
| Медиана | 42,9% |
| Среднее | 45,6% |
| Максимум | 106,2% |

Распределение:

| Диапазон наценки | Заказов |
|---|---:|
| < 25% | 1 |
| 25–35% | 7 |
| 35–50% | 5 |
| 50–75% | 6 |
| ≥ 75% | 1 |

Только 7 из 20 заказов близки к 30% (25–35%). Это **не доказывает**, что 30% — неверная цель: в «Итого себестоимость» может не быть производства, монтажа, проектирования и накладных. Если это только материалы, то 30% на полную `B` даст другую цену.

## 3. Наценка по фактическим затратам

Выборка: 27 заказов, где есть цена и фактические затраты > 0.

| Показатель | Значение |
|---|---:|
| Минимум | 16,5% |
| Медиана | 71,0% |
| Среднее | 1 464,8% (сильно искажено выбросами) |
| Максимум | 23 528% |

13 из 27 заказов имеют наценку > 75%. Причины: неполные фактические затраты, отсутствие труда/монтажа/доставки, ошибки ввода. Использовать эту выборку для утверждения коэффициентов нельзя.

## 4. Проблемы управленческого учёта

1. **Колонка «Прибыль» = цена − «Фактические затраты»**, а не цена − полная себестоимость. Если фактические затраты не заполнены, прибыль равна цене.
2. **Бонус дизайнера не вычитается из прибыли.** В 8 заказах бонус указан отдельно; в 27-м, 29-м, 32-м, 33-м, 35-м, 36-м, 37-м, 38-м он не уменьшает прибыль.
3. **Плановая и фактическая себестоимость не сопоставимы:** в 5 заказах факт больше плана; в 25 заказах плана нет.
4. **Нет структуры затрат:** материалы, производство, проектирование, монтаж, накладные, доставка, налоги и комиссии не разделены. Нельзя проверить, что входит в `B`.
5. **Нет налоговой и платёжной аналитики:** не видно, как оплачен заказ (нал/безнал/карта/QR), какая комиссия и налог.
6. **Есть технические строки** с датой `1900-02-28` и отрицательным «Осталось дней»; их нужно исключать из аналитики.

## 5. Вывод для финансовой политики

- Утвердить **30% наценку на `B`** можно как управленческое решение, но **нельзя подтвердить её калибровку** по этой выгрузке: нет полной структуры `B`.
- Если «Итого себестоимость» — это только материалы, текущая медиана 42,9% к материалам не равно 30% к полной `B`; цифры не сравнимы.
- Для пилота нужны 20 заказов с детализацией:

```text
цена
материалы
комплектующие
производство
проектирование
монтаж
накладные
доставка внутренняя
налоги
комиссии
бонус дизайнера
факт оплаты
```

- До получения детализации `B` и коэффициенты остаются `provisional`; окончательное КП не выпускается.
- Колонку «Прибыль» в таблице нужно пересчитать: `цена − полная себестоимость − налоги − комиссии − бонус дизайнера`, а не `цена − фактические затраты`.

## 6. Что сделать с таблицей

1. Добавить колонки структуры затрат (см. § 5).
2. Заполнить их по 20 заказам.
3. Пересчитать прибыль по формуле политики.
4. Отдельно отметить способ оплаты и комиссию.
5. Исключить технические строки и строки без цены/затрат из расчёта коэффициентов.
6. После этого сравнить фактические наценки с целевыми 30% и утвердить `v1.1`.
