## 1. Цель

**Один проект на входе — три готовых коммерческих предложения на выходе, без
ручного пересчёта материалов, работ и стоимости.**

Конвейер:

```text
Источник → Import → Recognition → Validation → Project → BOM → Nesting
        → Hardware → Price → Financial → Variants → Approval → Documents
```

## 6. Тестирование

Обязательные группы:

- **Импорт:** JPG/PNG/PDF, многостраничный PDF, `details.txt`, `.sto`,
  повреждённый файл, лимиты, параллельная загрузка, повторная загрузка.
- **Распознавание:** отсутствующие/конфликтующие размеры, несколько проекций,
  повторяющиеся модули, нестандартная конструкция.
- **BOM:** перегородки, ящики, стекло, задние стенки, цоколь.
- **Раскрой:** поворот, текстура, пропил, остатки, несколько листов.
- **Финансы:** изменение цены, отсутствие цены, скидка, безнал, доставка,
  округление, три варианта.
- **Документы:** цены из снимка, отсутствие себестоимости, подтверждение
  менеджера, история версий.
- **Архитектура:** нет второго расчётного пути; импорт не считает деньги.

Каждый этап добавляет тесты; покрытие изменённых модулей — не ниже 80 %,
общее — не ниже 63 % и не снижается.

## 11. Критерий окончательной готовности

Менеджер может:

1. Загрузить фото, чертёж, PDF или `details.txt`.
2. Получить распознанный проект с модулями и размерами.
3. Исправить только недостоверные данные.
4. Получить полную деталировку.
5. Получить реальные карты раскроя и закупочные количества.
6. Получить кромку и фурнитуру.
7. Получить себестоимость по актуальному прайсу.
8. Получить три независимых варианта.
9. Проверить и подтвердить расчёт.
10. Сформировать фирменное PDF-КП.

**Готовность измеряется точностью, временем и числом ручных операций, а не
количеством файлов и строк кода.**
