# Сверка независимого аудита (Master Prompt 2.0) с текущим кодом

Дата: 2026-11-17. Сверял отчёт «Независимый технический и производственно-финансовый
аудит Furniture Calculator» (97 абзацев, снимок 15.11.2026) с рабочим деревом после
плана v3 и закрытия P2-хвоста.

**Что именно сравнивалось**

| | Отчёт аудита | Сейчас |
|---|---|---|
| Коммит | `8de50b2` (15.11.2026) | `0aa36bc` + незакоммиченные правки |
| Тесты | 426 passed | **581 passed**, покрытие 59,12 % |
| Скидка | обработчик считает 5 из 10 статей | единый `CalculationService` (P1-01) |
| Скрипты аудита | приложены | запущены повторно (см. §2) |

Скрипты: `audit_probe_cost.py` — запущен целиком; `audit_benchmark_geometry.py` —
без сценария S16, потому что нулевой модуль теперь падает с `ValueError` (это и есть
доказательство закрытия P2-1).

## 3. Ответы на 4 вопроса (что можно ответить фактами, а что — ваше решение)

1. **Общие боковины.** Подтверждено собственником 17.11: **каждый корпус со своими
   боковинами**. Эвристика «70 % стыков» удалена из `quantity_calc`; группы выросли
   на 4,2–4,5 % к эталону (было −5,7…−10,7 %), `quantity_calc` и BOM совпали.
2. **Минимальная маржа / максимальная скидка.** Подтверждено: маржа **не ниже 15 %**
   над полной себестоимостью, скидка **до 10 %** без согласования. В коде:
   `min_margin_rate=0.15`, `max_discount_percent=10`; скидка выше потолка возвращает
   `PricingError` («нужно согласование директора»), согласование — явный
   `allow_above_limit=True` в сервисе.
3. **Безнал 1,13.** Подтверждено собственником 17.11: 13 % покрывают **и комиссию
   банка/инкассацию, и налоги, и риски** — одной цифрой, без разбивки. База — цена
   мебели после скидки и бонуса, **доставка не наценивается** (как в текущем коде).
   Формула не меняется; уточнена только формулировка в документах.
4. **Формат листа EGGER.** Подтверждено 17.11: EGGER и EXTRAVERT — **2750×1830**,
   LAMARTY/EMDIWAY — 2800×2070, SLOTEX — 3000×1200. Все остальные форматы в
   `SHEET_LDSP_BY_BRAND` подтверждены без изменений.
5. **Листы для цены.** Подтверждено: цена ЛДСП считается **по раскрою** (не по
   площади × 1,3). Раскрой строится до себестоимости; при неразмещённой детали —
   откат на площадь с предупреждением. Для текстурного ЛДСП поворот деталей
   запрещён (направление рисунка), сращивание рисунка не требуется.

## 4. Что это меняет в выводах аудита

- Оба P0, на которых держался вывод «со скидками использовать нельзя», **закрыты и
  заморожены тестами**: скидка считается полным путём, цена ниже полных затрат
  блокирует КП.
- P1-3 (раскрой) закрыт; остался вопрос единого подсчёта листов (P2-2) — это уже
  не «занижение в 5 раз», а расхождение 20–25 %.
- Отчёт описывает состояние **до** плана v3: 426 тестов и commit `8de50b2`.
  На 2026-11-17 — 581 тест, покрытие 59,12 %, `check_phases` 59/59.
- Перед коммерческой эксплуатацией остаются не «две критические», а решения:
  общие боковины, минимальная маржа, формат листа, единый подсчёт листов и
  терминология «закупка / полная себестоимость / маржа».
